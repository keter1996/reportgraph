# 功能清单

ReportGraph 是面向 Power BI PBIP 项目的本地图谱服务，用于把报表结构、模型结构、页面关系和字段绑定沉淀为可查询、可复用的 `Graph/` 产物。

## 当前能力

- 从 PBIP 项目初始化 Report Graph。
- 从 `.pbip` 文件路径或 PBIP 项目目录解析报表结构。
- 读取 PBIR 报表定义中的页面、视觉对象和视觉对象字段绑定。
- 读取语义模型中的表、列、度量值和关系。
- 支持 `model.bim` 和基础 TMDL 语义模型目录。
- 生成 `Graph/report-graph.json` 作为结构化图谱产物。
- 生成 `Graph/manifest.json` 作为版本、路径、指纹和刷新状态元数据。
- 生成 Markdown 上下文文件，方便人读和 Agent 消费。
- 支持图谱状态查看、更新、删除和结构化查询。
- 提供 CLI 命令入口。
- 提供 MCP stdio 服务入口，基于官方 .NET `ModelContextProtocol` SDK。
- 提供自包含发布脚本，适合客户机器或自动安装场景。
- 提供 `codex-install.json`，用于机器可读安装描述。

## CLI 命令

- `reportgraph init`
- `reportgraph update`
- `reportgraph delete`
- `reportgraph status`
- `reportgraph query`
- `reportgraph mcp`
- `reportgraph install-info`

## 查询能力

- `query graph`
- `query page <pageId>`
- `query page-bindings <pageId>`
- `query table <tableName>`
- `query visual <pageId> <visualId>`
- `query explore <from-page|from-table> <identifier>`

## MCP 工具

- `report.graph.load`
- `report.page.get`
- `report.page.bindings`
- `report.model.table.get`
- `report.visual.get`
- `report.graph.explore`

## 当前边界

- 仓库不附带用户业务 PBIP 项目。
- 使用者需要用自己的 PBIP 项目执行初始化、更新和查询。
- `Graph/` 是生成产物，不建议提交到 Git。
- Power BI Desktop 的 `.pbi/` 本地状态文件不参与图谱稳定性计算。
- PBIX 需要先转换为 PBIP 后再进入当前主链路。
